Personal portfolio website showcasing end-to-end systems in Financial NLP, Real-Time Computer Vision, Recommendation Engines, and Applied Machine Learning.

🌐 **Live Website**: [https://manavarora.dev/](https://manavarora.dev/)

---

## 🛠️ Built With

- **Framework**: React 18, Vite, TypeScript
- **Styling**: Plain CSS with custom properties (light and dark themes)
- **Icons**: React Icons
- **Deployment**: GitHub Pages via GitHub Actions

All copy, projects, skills and links live in `src/data/portfolio.ts`.

---

## ✨ Key Features

- **Project case studies**: Each project leads with its headline metrics, stack, and links to source or a live demo.
- **Experience timeline**: Internship and open-source roles plus education.
- **Light and dark themes**: Follows the system setting, with a toggle that remembers your choice.
- **Accessible and fast**: Semantic markup, keyboard-friendly navigation, reduced-motion support, and no animation library.
- **Fully responsive**: Works from 320px phones up to wide desktops.
