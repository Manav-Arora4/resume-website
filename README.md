## 🛠️ Built With

- **Framework**: React 18, Vite, TypeScript
- **Styling & Aesthetics**: Vanilla CSS, Modern Glassmorphism, Dark Navy & Cyan Theme
- **Animations**: Framer Motion
- **Icons**: React Icons
- **Deployment**: GitHub Pages

---

## ✨ Key Features

- **Interactive Projects Showcase**: Dynamic project selector with Left/Right navigation, direct GitHub repositories, and live demo links.
- **Tabbed Technical Skills**: Categorized capabilities across Languages, Machine Learning, Frameworks, Databases, Cloud & Hosting, and Tools.
- **Verified Certifications Carousel**: Stanford Online & DeepLearning.AI credentials with direct verification links.
- **macOS IDE Terminal**: Code-styled About Me terminal window with syntax highlighting.
- **Scroll Progress & Dynamic Animations**: Real-time reading progress bar, floating ambient particles, and dynamic specialty rotator.
- **Fully Responsive**: Optimized for desktop, tablet, and mobile devices.
